# barebones

A simple app for managing feature requests and tracking their progress on a roadmap.

- Create and upvote feature requests
- Requests view with search and sorting
- Roadmap view grouped by Queued, In Progress, Completed
- Light, dark and system themes

## Tech

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- next-themes

## Getting started

```bash
git clone <repository-url>
cd barebones
npm install
npm run dev
```

## Scripts
- `npm run dev` - start the dev server
- `npm run build` - build for production
- `npm run start` - start the production server
- `npm run lint` - run ESLint
